# Artwork sources

- `icon.png` — canonical master app icon (1024px). `src-tauri/app-icon.png` is a byte-identical copy that the Tauri bundler references; `src-tauri/icons/**` are generated from it (Windows/Android/iOS sizes are kept for the planned cross-platform ports — see wiki/Roadmap).
- `mascot.jpg` — original artwork the icon was derived from.
- `src/assets/icon.png` and `public/icon.png` are the padded/cropped derivative used in the README and in-app dialogs.
